# Codex Context: Vanadisvagen 2 Apartment

This workspace is an apartment planning hub for Vanadisvagen 2 in Stockholm.

## Core Context

- The user recently bought the apartment.
- Access date is 2026-12-21.
- The user will interact with this project through Codex rather than manually maintaining a separate app.
- Codex should help organize information, find existing context, create and update project notes, turn thoughts into tasks, and prepare shareable summaries for the user's girlfriend.
- Existing listing/source material should be preserved and not reorganized unless explicitly requested.

## How To Work In This Workspace

- Start with `APARTMENT_HUB.md` for the map of the project.
- Use `00_Home/Inbox.md` for quick capture of raw thoughts.
- Use `00_Home/Task_Board.md` for active tasks.
- Use `00_Home/Decision_Log.md` for decisions that have been made or need to be made.
- Use `00_Home/Budget_Tracker.md` for estimates, quotes, and actuals.
- Use `02_Shared/Shared_Notes.md` and `02_Shared/Weekly_Check_In.md` for material meant to be easy to share with the user's girlfriend.
- Add new project pages in `01_Projects/` using `04_Templates/Project_Template.md`.

## Working Style

- Keep the system lightweight and easy to maintain through conversation.
- Prefer updating existing notes over creating many new files.
- When the user shares a thought, decide whether it belongs in the inbox, a task, a decision, a budget line, a project note, or shared notes.
- When summarizing for the user's girlfriend, write in plain, warm language with clear decisions, open questions, and next actions.
- Preserve existing source documents, listing images, PDFs, and raw captures.
